# IVGrads@NCSU Website

This is the latest editable website, including all requested design changes.

## Open it
Extract the ZIP, then open index.html in your web browser.
Alternatively, run `python3 -m http.server 8000` in the extracted folder and visit http://localhost:8000.

## Edit it
- index.html: content, links, meeting details, and carousel slides
- styles.css: colors, typography, responsive layout, and dividers
- app.js: navigation, carousel, dialogs, email drafts, and calendar downloads
- assets/: photographs, logos, and locally bundled fonts

## Publish it
Upload the extracted files to a static website host, keeping the folder structure intact. No build step or package installation is required.

## Contact flow
The contact form opens an email draft for the visitor to review and send; it does not submit to a backend. Carousel content includes Tuesday fellowship and links to Instagram/Discord event updates.
