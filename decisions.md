# Decisions

- The site is a single page (About, Meetings, Contact sections) because that keeps it simple and leaves fewer files to maintain.
- The site owner writes all the copy, and the template only marks where text goes with `EDIT` comments, so the site doesn't read as AI-written.
- The header reads "InterVarsity Graduate Christian Fellowship at NCSU" so visitors can tell right away which campus the group belongs to.
- Contact goes through a `mailto:` link rather than a form, because GitHub Pages has no backend.
- The design is a plain single column with a serif font and colors taken from the logo, with no cards, gradients or icons, so it doesn't look templated.
